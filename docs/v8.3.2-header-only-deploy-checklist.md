# v8.3.2 Header-Only Cmd Delivery Deploy Checklist

1. Install the new tree with the normal guarded installer path.
2. Restart the cmd-pane Claude session after install so it reloads `config/claude-md-ccb.md`.
3. Run the auto-pend smoke test: inject `[CCB] job=target=cmd from=agent1 bytes=0 pend=ccb-pend` into the restarted cmd pane and confirm Claude runs `ccb pend cmd`.
4. Write `.ccb/ccbd/cmd-header-only-compatibility.json` only after the smoke test passes, using schema version 1 with the current project id, build commit, prompt instruction hash, smoke job id, smoke reply id, cmd pane id, `observed_auto_pend=true`, and creation timestamp.
5. Restart/remount ccbd so it validates the marker at startup. Enable `CCB_CMD_DELIVERY_MODE=header_only` only after marker validation passes.
6. If the restart smoke test or marker validation fails, keep `CCB_CMD_DELIVERY_MODE=full_body` and retry after remounting the cmd pane.

The beta gate is restart-based: stale pre-v8.3.2 sessions stay on full-body delivery, while restarted sessions may use header-only delivery after the smoke test proves auto-pend instruction pickup.
